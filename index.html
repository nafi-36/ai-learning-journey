BEFORE YOU BEGIN

Device & setup guide

You can start learning AI without an expensive computer. Choose the setup that matches what you want to practice.

💡
You do not need a high-end GPU on day one.

Most beginner exercises, Python notebooks, and classical machine learning can run on an ordinary modern laptop. For heavier deep learning, use cloud notebooks such as Google Colab or Kaggle.

💻Starter setup

Fundamentals & basic ML

Months 1–2 · Python, notebooks, datasets, Scikit-learn

  • CPU: Modern Intel Core i3 / Ryzen 3 or Apple Silicon
  • RAM: 8 GB minimum, 16 GB recommended
  • Storage: 10–20 GB free SSD space
  • GPU: Not required
  • Internet: Stable connection
A regular student laptop is usually enough.
🧠Recommended

Deep learning & AI apps

Months 3–4 · Neural networks, NLP, LLM APIs, small experiments

  • CPU: Intel Core i5 / Ryzen 5 / Apple M-series
  • RAM: 16 GB recommended
  • Storage: 30–50 GB free SSD space
  • GPU: Optional; cloud GPU is useful
  • Internet: Stable, preferably unlimited
Best balance for learning and building projects.
⚙️Advanced setup

Local model experimentation

Months 5–6 · Larger models, local inference, heavier training

  • CPU: Modern 6-core or better
  • RAM: 32 GB+ recommended
  • Storage: 100 GB+ free SSD space
  • GPU: NVIDIA GPU with 8–12 GB+ VRAM as a practical starting point
  • Internet: Stable for model downloads
Useful for local experimentation, not mandatory for course completion.

Important note about training AI models

Training a large language model from scratch requires substantial compute and is outside the needs of this roadmap. The projects here should focus on using pretrained models, fine-tuning small models when appropriate, API integration, and cloud-based experiments. Always check the current hardware limits and pricing of cloud platforms before running GPU workloads.
